# Tailwyndz Propel – Git & Version Control Showcase

Practical repository demonstrating atomic micro-commits, Conventional Commits formatting, branch merging, and conflict resolution.

## Practices Demonstrated
- **Atomic Micro-Commits:** One logical change per commit.
- **Line-Level Staging:** Splitting multi-feature edits inside VS Code Source Control.
- **Branch & Merge Hygiene:** Feature branching and conflict resolution.
